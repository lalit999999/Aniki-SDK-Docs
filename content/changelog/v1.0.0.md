## Features

- A markdown content loader (`lib/content`) that reads `content/docs`, validates frontmatter with Zod, parses markdown into an AST, and derives slugs, routes, headings, a table of contents, and reading time.
- A documentation layout: sidebar navigation grouped by category, breadcrumbs, a right-hand table of contents, previous/next page links, and an "Edit on GitHub" link pointing at the exact source file.
- Full-text search (`lib/search`) over every section of every page, served as a static index and surfaced through a `⌘K` command palette with match highlighting, snippets, and recent searches.
- A document metadata bar (category, reading time, last-updated date, tags) and copy-page-URL / copy-heading-link actions.
- Documentation versioning: a declared version registry, a `/docs/<version>/*` URL scheme for non-latest versions, a version switcher in the header, deprecation notices for individual pages, and legacy-version banners.
- This changelog, built on the same markdown pipeline as the docs themselves.

## Fixes

- Corrected heading extraction to walk the parsed markdown AST rather than regex-matching `#` characters, so fenced code blocks containing lines like `# pnpm` no longer produce phantom table-of-contents entries.
- Fixed sidebar identifier splitting to break camelCase and hyphenated identifiers into words before lowercasing, rather than after, so search matches expected tokens.
- Fixed a `useRecentSearches` render loop caused by recomputing a new array identity on every render.

## Breaking Changes

None - this is the first release.
